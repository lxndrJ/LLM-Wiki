# Rohe Quellen

Lege hier deine Quelldokumente ab (Markdown, PDF, Text, …). Das LLM liest daraus, schreibt aber nie in dieses Verzeichnis.

- Bilder und Anhänge gehören nach `assets/`.
- Dateinamen sprechend wählen, z. B. `2026-04-karpathy-llm-wiki.md`.

Dieses Verzeichnis ist deine **Quelle der Wahrheit** — unveränderlich aus Sicht des LLM.
